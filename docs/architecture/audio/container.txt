This is the container view of tech-world. Five parts work together. The agents directory holds reusable subagent personas: web scraping, 3D frontend, responsive accessibility, and architecture diagramming. The skills directory defines policies: MongoDB-only data management, living documentation, and AdSense compliance. The hooks directory enforces those policies automatically: documentation reminders on every prompt, accessibility checks on every file change, an AdSense gate on every push, and an architecture-first gate for new work. The scraper package is a working Python toolkit with static, dynamic, and A P I fetch modes. Finally, the changelog and docs record every change, with versioned release notes cut at each release.
